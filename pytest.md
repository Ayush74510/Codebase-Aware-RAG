NORMAL PYTHON SCRIPT ->    .py                                           
                            ↓
                            python file.py
                            ↓
                            Python executes instructions
                            ↓
                            output / side effects                                              


PYTEST TEST ->  test_*.py or *_test.py
                    ↓
                    pytest
                    ↓
                    discover test_ functions
                    ↓
                    execute them
                    ↓
                    assertions
                    ↓
                    PASS / FAIL
